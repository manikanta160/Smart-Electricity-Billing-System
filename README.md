# ⚡ Smart Electricity Billing System

A simple and attractive desktop application built using Python and Tkinter to calculate electricity bills and provide energy-saving recommendations.

## ✨ Features

* 🎨 Attractive graphical user interface
* 👤 Customer information input
* ⚡ Automatic electricity bill calculation
* 💰 Energy charges and fixed charges
* 📊 Electricity consumption analysis
* 💡 Smart energy-saving recommendations
* ⚠️ High-consumption alerts
* 🔄 Clear and recalculate bills

## 🛠️ Technologies Used

* Python
* Tkinter
* Python IDLE

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open `ElectricityBillingSystem.py` using Python IDLE.
4. Select **Run → Run Module** or press F5.
5. Enter customer details and electricity consumption.
6. Click **Calculate Bill** to view the result.

## 🧮 Billing Calculation

The application calculates electricity charges using sample consumption-based tariff slabs and a fixed charge.

**Note:** The example tariff rates are for demonstration purposes and do not represent official electricity tariffs.

## 🎯 Project Objective

The objective of this project is to simplify electricity bill calculation through an easy-to-use graphical application and encourage efficient electricity consumption through recommendations.
